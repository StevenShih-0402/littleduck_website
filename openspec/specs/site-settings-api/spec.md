# site-settings-api Specification

## Purpose
提供網站設定的後端 API：讓前台讀取站台中繼資料、後台更新設定（標題、標語、社群連結、公告、贊助級距），取代前端僅存在 localStorage 的設定資料。

## Requirements

### Requirement: 公開讀取網站設定
系統 SHALL 提供公開讀取端點，回傳前台渲染所需的站台設定（標題、標語、社群連結、公告、贊助級距等）；讀取不需要管理員身分。

#### Scenario: 讀取目前設定
- **WHEN** 未帶權杖呼叫設定讀取端點
- **THEN** 回傳 200 與目前完整的網站設定

### Requirement: 後台更新網站設定
系統 SHALL 提供需管理員身分的設定更新端點；更新後 MUST 立即反映於公開讀取結果。無效或缺漏的設定內容 MUST 回傳 400 並維持原設定不變。

#### Scenario: 成功更新設定
- **WHEN** 管理員以有效權杖更新網站標語與公告
- **THEN** 回傳 200，且後續公開讀取回傳更新後的值

#### Scenario: 未授權的更新
- **WHEN** 未帶有效權杖呼叫設定更新端點
- **THEN** 回傳 401，且設定不變

#### Scenario: 無效設定內容
- **WHEN** 管理員提交格式錯誤或缺漏必要欄位的設定
- **THEN** 回傳 400 與統一錯誤格式，設定維持原狀
