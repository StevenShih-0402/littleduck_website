# Spec Delta

## Purpose

提供文章內容的後端 API：對外公開列表與單篇讀取，對後台提供建立、修改、刪除與發布狀態管理，取代前端僅存在 localStorage 的文章資料。

## ADDED Requirements

### Requirement: 公開讀取已發布文章
系統 SHALL 提供文章的公開讀取端點：列表僅回傳已發布（published）文章，並提供以文章 id 讀取單篇的端點；讀取不需要管理員身分。文章 MUST 含前台渲染所需欄位（標題、分類、日期、狀態、瀏覽數、摘要與內文等）。

#### Scenario: 列表只含已發布文章
- **WHEN** 未帶權杖呼叫 `GET /api/v1/articles`
- **THEN** 回傳 200 與已發布文章清單，草稿不出現在結果中

#### Scenario: 讀取單篇文章
- **WHEN** 以存在的文章 id 呼叫單篇讀取端點
- **THEN** 回傳 200 與該文章完整內容

#### Scenario: 文章不存在
- **WHEN** 以不存在的文章 id 呼叫單篇讀取端點
- **THEN** 回傳 404 與統一錯誤格式

### Requirement: 後台管理文章
系統 SHALL 提供需管理員身分的文章建立、修改與刪除端點，並可設定發布狀態（草稿／已發布）。後台列表 MUST 能同時取得草稿與已發布文章。

#### Scenario: 建立草稿文章
- **WHEN** 管理員以有效權杖建立一篇狀態為草稿的文章
- **THEN** 文章被儲存，公開列表不顯示它，後台列表顯示它

#### Scenario: 發布文章
- **WHEN** 管理員將一篇草稿文章的狀態改為已發布
- **THEN** 該文章出現在公開列表

#### Scenario: 刪除文章
- **WHEN** 管理員刪除一篇文章
- **THEN** 該文章不再出現於公開與後台列表

#### Scenario: 未授權的管理操作
- **WHEN** 未帶有效權杖呼叫文章建立／修改／刪除端點
- **THEN** 回傳 401，且資料不變
