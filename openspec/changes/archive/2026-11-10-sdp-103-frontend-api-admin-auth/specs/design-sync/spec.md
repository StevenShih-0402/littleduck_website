# Spec Delta

## ADDED Requirements

### Requirement: 標記刻意分歧的對應
同步基準 SHALL 能把某個設計檔與其前端對應標記為「刻意分歧」，用於前端檔案因功能需要（如 `store/lake.js` 改接後端 API）而不再追隨設計檔的情形。對於被標記刻意分歧的對應，差異報告 MUST 不將其列為待同步變更，且使用者觸發的同步 MUST NOT 以設計檔覆寫該前端檔案。

#### Scenario: 被標記的檔案不列入待同步
- **WHEN** 某設計檔與前端對應被標記為刻意分歧，且該設計檔雜湊與基準不同
- **THEN** 差異報告不把它列為待同步變更，而標示為刻意分歧

#### Scenario: 同步不覆寫刻意分歧的前端檔案
- **WHEN** 使用者觸發同步，範圍內包含被標記刻意分歧的對應
- **THEN** 同步不以設計檔覆寫該前端檔案，其餘未標記的對應照常移植
